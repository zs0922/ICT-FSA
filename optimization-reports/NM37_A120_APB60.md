# NM37 A120/APB60：A110/APB55 的仅改频率实验

## 当前结论

**保留 C0：120MHz DUT / 60MHz APB，仅修改频率，PE 流水深度不变。** 独立工作区已完成编译、等价验证、功能回归、完整综合/布局/布线及布线后优化；同一 routed DCP 的最终只读验收 `reaudit01` 退出码为 0，`constrained_sta_passed=true`、`hbm_startup_physical_passed=true`。

DUT setup **+0.235ns**，达到实验前设定的 ≥0.2ns 工程裕量；整板 WNS **+0.041ns**、WHS **+0.010ns**，setup/hold/pulse 失败端点均为零。因此没有启动 FMA 结果选择后移候选 C1。整板最紧路径在 PCIe，后续提频仍需完整实现与验收。

这是受约束路径的整板 STA 和结构验收通过；继承的 CDC 告警及约束覆盖边界见下文，`board_signoff=false`。尚未上板测试，未导出 A120 bitstream；没有 push。原审计器的周期舍入误报、修复及独立验收记录全部保留。

A110 数据取自已接受的 `apb110-20261020/reaudit04/obj`；A120 最终数据取自 `reaudit01/obj`，与原构建最终报告及 `routed-analysis-c0-build02` 独立诊断一致。只读打开实际 DCP，前后 SHA256 不变。对比 JSON 为每项指标保留报告路径、行号/JSON 字段和 SHA256。

A120 DUT 最差路径为：

```text
dutDomain/fsa/fsa/sa/mesh_6_12/expInput_exp_reg[1]/C
  → .../macUnit/mulAddExp2/fma/adderOutAbs_reg[53]_bret/D
```

数据路径 8.028ns = 逻辑 2.140ns + 布线 5.888ns（73.343%）；25 个逻辑层级包含 9 个 CARRY8 和 16 个 LUT。时钟偏斜 −0.014ns、不确定度 0.081ns。路径名中的 `_bret` 来自原有 Vivado retiming 流程；本轮没有手工移动 FMA 选择器或增加流水级。

DUT top1000 中，970 条终点属于 PE FMA 加法结果寄存器，13 条 CMP 内部路径（最差 +0.922ns），9 条 CMP→PE link（+1.008ns），5 条复位上游路径（+0.256ns），其余为 PE/阵列 link 路径。它是最差路径样本，不是全网表路径普查。

额外按起点过滤的报告显示：PE FMA 内部寄存器之后最差 +1.052ns，accumulator +1.274ns，scratchpad RAM 起点 +5.433ns，末级复位副本 Q 起点分发 +3.602ns。起点过滤不能代表整个模块的所有输入路径；尤其复位上游 `sync_1_reg`→末级副本只有 **+0.256ns**，不能用 +3.602ns 概括全部复位路径。

整板最差 +0.041ns 位于 PCIe：`PCIE4CE4/CORECLK`→`pcie_rq_seq_ret_wr_ff_reg[4]/D`，是 500MHz core 与 250MHz AXI 相关时钟间、要求 2ns 的数据 setup 路径。数据延迟 1.695ns（逻辑 0.976ns、布线 0.719ns），时钟偏斜 −0.243ns。FMA 选择后移不会直接改善这条路径。该整板裕量偏小，后续更换实现参数或再次提频必须重新检查全部时钟域，不能从 DUT slack 外推整板最高频率。

实际 Clock Wizard 为输入 100MHz、MMCM M=12 / D=1、输出分频 10/20；输出 120/60MHz，报告 jitter 112.035/127.801ps。HBM reference/reset monitor 仍为 100MHz。APB 的周期、脉宽数据来自 `HBM_SNGLBLI_INTF_APB/PCLK` 原语检查，不仅是波形算术。
