# A100复现修正：移除不匹配的历史扇出约束

从固定A100提交`f8650f9576bf681bfae38a2ab40718fc2ace4262`独立重建时，Vivado报告`nm37-config.xdc`中的`*sram_accRAM_fullWrite_0_addr_REG*`没有匹配cell，随后`set_property MAX_FANOUT 128`产生`Common 17-55`。旧A100原始构建日志也存在相同提示。

该约束继承了早期寄存器命名。现代A100生成RTL使用`...addr_r...r_3`地址寄存器链，因此本修正移除失效命令及声称它已起效的过时说明；不把限制重新套到新寄存器、不改变RTL/时钟/有效时序约束，也不改A70历史版本。

本提交仅记录输入修正，不代表重新布局布线或实板验收通过。修正前结果保留，修正后的编译、定向验证、各尺寸仿真和完整布局布线应在独立源码/输出重新执行，并比较生成RTL和实际时序资源。
